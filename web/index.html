💡 Key Observation for Phase 2:

Under Balanced Workloads, static distribution operates near optimal speedup (up to 3.88x on 4 cores) with Jain's Index = 1.000. However, under Skewed Workloads, static Round-Robin drops efficiency to ~37% as Core 0 stays 100% busy while Cores 1–3 sit idle for 80%+ of execution. In Phase 2, we will implement predictive load balancing and task migration to proactively offload tasks from overloaded cores to idle cores!
